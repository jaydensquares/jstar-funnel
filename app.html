Meta (Facebook / Instagram)

Where do I find these?
  1. Open Meta Events Manager → Data sources → your Pixel.
  2. The Pixel ID is the number under its name.
  3. For the token: Settings → Conversions API → Generate access token.

Google Ads

Where do I find these?
  1. Google Ads → Goals → Conversions → New conversion action → Website → "Submit lead form".
  2. Choose "Use Google tag" → install manually.
  3. In the event snippet, send_to looks like AW-123456789/AbC-D_efG. The part before the slash is the tag ID; after it is the label.
